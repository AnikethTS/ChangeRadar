How it works

One command. The same JAR runs on a laptop and in GitHub Actions. It never builds or tests the repository it is reading.

  1. Diff

    Compare explicit --base and --head refs. Additions, edits, deletions, and renames are listed.

  2. Symbols

    Map changed lines to types and functions in Java, Kotlin, TypeScript, JavaScript, Python, PHP, and SQL. Comment-only diffs are format-only, not API occupancy.

  3. Evidence

    Report likely callers and related tests with a confidence label. Optional policies can fail the job. Exit 0 means analysis finished, not that the change is safe.

Contribute

Fork the repo, run ./gradlew check, and open a focused pull request.
